# Personal Portfolio & Showcase

A modern, responsive, and performance-optimized personal portfolio web application built with **Next.js 14**, **React**, and **Material UI (MUI)**. Built with dark theme aesthetics, custom typography, micro-interactions, and modular layout components.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **UI & Styling:** [Material UI (MUI v5)](https://mui.com/), `@emotion/react`, `@emotion/styled`
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** `@mui/icons-material`
- **Language:** TypeScript
- **Deployment:** Vercel / Netlify

---

## ✨ Features

- **Responsive Design:** Optimized across mobile, tablet, and desktop viewports.
- **Dark Theme Aesthetics:** Configured custom dark theme palette with crisp typography hierarchy.
- **Interactive UI Cards:** Micro-interactions, soft borders, and hover elevations for project showcases.
- **Clean Structure:** Modular grid layouts built to minimize empty spacing and vertical friction.
